# Phase 2B – menschlicher Nutzungstest

Stand 21.10.2026 · Vorlage, **noch keine beobachteten Ergebnisse**. Phase 3 bleibt gesperrt. Ziel ist die Bedienbarkeit und die neue Adventure-Experience; Placeholder-Grafik wird nicht bewertet.

## Selbst starten

Produktionsbuild öffnen, „Neues Spiel“, eines der beiden Presets wählen, „Los geht’s“. Auf freien Boden tippen, um zu gehen; Personen und Gegenstände direkt antippen. Die Figur geht zur Interaktion hin. Jonas hat eine blaue Kappe. Notizen erinnern an die aktuelle Frage. Menü → Orte und Dinge bietet einen zugänglichen Weg zu denselben Objekten; die Figur läuft auch dabei hin.

Menü → Einstellungen & Zugänglichkeit: Tap-to-Move oder gehaltene Richtungstasten, Hinweise auf Anfrage bzw. erste Ideen in Notizen, größere Schrift. Beide Bewegungsvarianten bleiben Experimente. Tastatur: Pfeile/WASD; E am Objekt; Tab und Enter für Weltobjekte und Menüs; Escape schließt ein Fenster, im Raum öffnet es das Menü. Betriebssystem-Einstellung „Bewegung reduzieren“ wird übernommen. Debug ist für den Test nicht erforderlich; F2 bzw. `?debug=1` öffnet ihn bei Bedarf.

Der Stand wird lokal auf diesem Browser/Origin gespeichert. Fortsetzen öffnet die Welt; ein Gespräch wird durch erneutes Ansprechen fortgeführt. Ein halbfertiger Regalplan bleibt an der Werkbank erhalten. Neues Spiel ersetzt die aktuelle Runde nach Rückfrage, wenn ein Stand vorhanden ist. Frühere Phase-1/2-Teststände starten wegen geänderter Aufgabe neu; eine vollständige Sicherung bleibt im Debug-Modus exportierbar.

Offline erst nach vollständigem Erstladen: Im Menü muss „Offline bereit“ stehen. Danach Netzwerk aus und die Seite neu öffnen. Auf dem Mac funktioniert dies über localhost; ein iPhone im WLAN braucht für Service Worker vertrauenswürdiges HTTPS. Eine einfache LAN-HTTP-Adresse reicht zur Online-Bedienprobe, nicht zum Offline-Nachweis. Browserdaten löschen entfernt auch lokale Saves und Offline-Dateien.

## Kurzer Test ohne Entwicklerwissen

Nach Möglichkeit 3–5 unvorbereitete Personen einzeln testen, Zielgruppe 13–18 mit passender Betreuung/Einwilligung. Der Auftraggeber kann vorab denselben Ablauf prüfen. Beobachten statt die richtige Klickfolge erklären. Keine Namen oder unnötigen personenbezogenen Daten protokollieren.

Einzige Einstiegsaufgabe: **„Schau dich im WERK um. Finde heraus, was Jonas braucht, und hilf ihm, wenn du möchtest.“** Die folgenden Beobachtungspunkte bleiben bei der Testleitung, damit sie keine Suchanleitung werden:

| Beobachtung | Notiz / Zeitpunkt / benötigte Hilfe |
|---|---|
| Versteht die Person Start und Bewegung? | |
| Findet sie Jonas und beginnt das Gespräch? | |
| Untersucht sie freiwillig etwas, etwa die Tasse? | |
| Versteht sie Standort und beide Messpunkte? | |
| Liest sie das Maß und kann nach falscher Eingabe weiter? | |
| Findet und vergleicht sie Materialproben vor der Auswahl? | |
| Versteht sie mehrere sinnvolle Material-/Verfahrenswege? | |
| Findet sie die Werkbank und versteht Auswahl → Ziel? | |
| Kann sie Böden und Kisten sinnvoll anordnen? | |
| Erkennt sie, warum eine Kiste nicht passt? | |
| Erkennt sie Regal und eingeräumte Kisten als eigene Folge? | |
| Nutzt sie Berufsbezug freiwillig? | |
| Findet sie nach Unterbrechung wieder hinein? | |

Beim Planen die Zeit ab dem ersten bewussten Bedienversuch bis zum passenden Plan beobachten. **30–60 Sekunden ist ein unbestätigtes Ziel**, kein Timer und keine Mindestdauer. Ebenfalls gesamte Spielzeit, Such-/Lesezeit, Abbrüche und Hilfen getrennt notieren. Eine schnelle automatisierte Klickfolge sagt darüber nichts aus.

Wenn jemand feststeckt, erst fragen „Was versuchst du gerade?“; dann Notizen/Hinweise anbieten. Konkrete Lösung erst zuletzt zeigen und als Hilfe protokollieren. Bei einzelnen Personen die Bewegungsvarianten in wechselnder Reihenfolge ausprobieren; je eine kleine vergleichbare Strecke gehen lassen. Präferenz und Fehlbedienungen erfassen, ohne daraus bei kleiner Stichprobe eine endgültige Produktentscheidung abzuleiten.

## Nachgespräch und Entscheidung

Kurze offene Fragen: Was wolltest du gerade tun? Wo war unklar, was möglich ist? Was hat deine Entscheidung beeinflusst? Welche Veränderung hast du bemerkt? Was würdest du als Nächstes erkunden wollen?

Befunde als konkrete Beobachtung festhalten, z. B. „Messpunkt 2 dreimal nicht gefunden“, statt „Touch ist schlecht“. Priorisieren: blockiert / benötigt Hilfe / Irritation. Pro Befund Gerät, Browser, Schriftgröße und Steuerung notieren. Keine Berufseignungsbewertung, Prozentnote oder Wirksamkeitsbehauptung.

**Review-Vorlage:** Datum/Gerät, anonyme Testkennung, vollständiger Ablauf ohne Hilfe ja/nein, Hilfen, Planzeit, wichtigste Irritation, freiwillige Entdeckung, sichtbare Folge erkannt, Bewegungspräferenz, nächste Korrektur. Auftraggeber entscheidet anschließend über Korrekturen oder Freigabe. Phase 3 beginnt nicht automatisch.
